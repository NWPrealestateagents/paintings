# 聂泽昭 – Chinese watercolor painting

All files live in one folder, with no sub-folders, so you can select every file
and drag them all into the GitHub upload page at once.

## Put it online

1. Create a public repository on GitHub.
2. Click **Add file, Upload files**. Select every file in this folder and drag
   them in. Click **Commit changes**.
3. Settings, Pages: Source is **Deploy from a branch**, branch `main`, folder
   `/ (root)`. Save.
4. Your site is at `https://YOUR-USERNAME.github.io/REPO-NAME/` and the iPad
   slideshow is at `.../slideshow.html`.

## Event dates

Edit `events-data.js` (the instructions are at the top of that file).
